# Get started by role

Adobe Commerce documentation is organized across several repositories and sites. The right starting point depends on your role and, for administrators and merchandisers, on which platform and merchandising path your project uses. See [Products](../products/overview.md) if you're not yet sure which platform applies to you.

## For business practitioners

Learn what Adobe Commerce is and how the Admin and storefront work together.

- [[!DNL Adobe Commerce as a Cloud Service] overview](/help/cloud-service/overview.md)

- [[!DNL Adobe Commerce Optimizer role-based workflows]](/help/optimizer/get-started.md#role-based-workflows)

- [Adobe Commerce getting started guide](https://experienceleague.adobe.com/en/docs/commerce-admin/start/guide-overview)


## For merchandisers

Adobe Commerce has two merchandising paths. The one that applies and is available to you depends on your backend—not your role:

- **[!DNL Live Search], [!DNL Product Recommendations], and [!DNL Catalog Service] extensions**: Used on [!DNL Adobe Commerce as a Cloud Service] and Adobe Commerce (on Cloud or on premises). See the following guides:

- [What is Live Search?](/help/live-search/overview.md)
- [What are Product Recommendations?](/help/product-recommendations/overview.md)
- [Catalog Service for Adobe Commerce](/help/catalog-service/overview.md).

- **Native merchandising in [!DNL Adobe Commerce Optimizer]**: Used when Adobe Commerce on Cloud or on premises is connected to [!DNL Adobe Commerce Optimizer] through the [!DNL Adobe Commerce Optimizer Connector]. See the [Merchandising overview](/help/optimizer/merchandising/overview.md).

## For administrators

Setup differs by platform, and by whether your project uses [!DNL Adobe Commerce Optimizer]:

- **[!DNL Adobe Commerce as a Cloud Service]**: Commerce services are installed and configured automatically. See [Getting started with Adobe Commerce as a Cloud Service](/help/cloud-service/getting-started.md).

- **[!DNL Adobe Commerce Optimizer]**: A SaaS product that you set up independently of your Commerce backend. See [Get started with Adobe Commerce Optimizer](/help/optimizer/get-started.md).

- **[!DNL Adobe Commerce Optimizer Connector] and [!DNL Adobe Commerce Optimizer Connector for B2B]**: Used to connect Adobe Commerce (on Cloud or on premises) to Adobe Commerce Optimizer. See [Get started with Adobe Commerce Optimizer Connector](/help/aco-connector/get-started.md).

- **Adobe Commerce on Cloud or on premises (PaaS)**: Install each Commerce services extension before you configure it. See the guides for each extension for detailed instructions.

- [Get started with Live Search](/help/live-search/install.md)
- [Install and configure Product Recommendations](/help/product-recommendations/install-configure.md)
- [Catalog Service installation](/help/catalog-service/installation.md).

- For platform administration for Adobe Commerce on Cloud or on premises, see:

- [Commerce on Cloud Infrastructure guide](https://experienceleague.adobe.com/en/docs/commerce-on-cloud/user-guide/overview)
- [Adobe Commerce Operational Guides](https://experienceleague.adobe.com/en/docs/commerce-operations/operational-guides/home) for on-premises.
