# About the Commerce Information Center

The Commerce Information Center is a cross-product entry point into the Adobe Commerce documentation ecosystem. Use it to find the right product, implementation guidance, and architecture recommendations across Adobe Commerce, [!DNL Adobe Commerce Optimizer], [!DNL Adobe Commerce as a Cloud Service], and related Commerce services—without having to search multiple documentation sites.

The authoritative, in-depth documentation for each product continues to live in its own guide. The Information Center curates and links to that content so you can start in one place and get to the right destination faster.

## Getting started

| Section | Use it to |
| ------- | --------- |
| [ Get started by role](get-started/get-started-by-role.md) | Find a starting point based on your role—business practitioner, merchandiser, administrator, developer, solution architect, or partner. |
| [Platforms and services](portfolio/platform-and-services.md) | Understand the Adobe Commerce product portfolio and identify which products and services fit your requirements. |
| [Choose a Commerce option](portfolio/choose-commerce-option.md) | Get guidance on selecting the right Commerce offering based on your deployment preferences, operational requirements, and desired level of infrastructure management. |
| [Storefronts](storefronts/overview.md) | Learn about the different storefront options available within Adobe Commerce. |
| [AEM Assets integration for Commerce](aem-assets/aem-assets-integration.md) | Add centralized digital asset management to any Commerce or Optimizer architecture. |
| [APIs](apis/commerce-apis.md) | Explore the API families used across Commerce Foundation, Storefront Services, and Commerce Optimizer. |
| [Implementation guides](implementation-guides/overview.md) | Follow cross-product guidance for common implementation journeys, such as building a storefront or connecting Commerce services. |
| [Architecture options](architecture-options/overview.md) | Compare the supported Commerce architectures and review reference patterns that span multiple Commerce products. |
| [Insights and guidance](guidance-and-insights/overview.md) | Find strategic guidance, including white papers, security recommendations, and best practices, as they become available. |
| [Migration and adoption](migration-adoption/overview.md) | Plan a move between architectures or a phased adoption of Adobe Commerce Optimizer. |

>[!NOTE]
>
>The Commerce Information Center does not replace product documentation. For step-by-step configuration and reference material, follow the links in each section to the authoritative product guide.
