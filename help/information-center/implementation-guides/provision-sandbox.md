# Provision sandbox environments

How you provision a sandbox depends on which Adobe Commerce product you use.

## Getting started

- **[!DNL Adobe Commerce as a Cloud Service]**—Use the Commerce Cloud Manager self-service provisioning portal to launch sandbox and production instances. See [Getting started with Adobe Commerce as a Cloud Service](/help/cloud-service/getting-started.md).

- **Adobe Commerce on Cloud (partners)**—Submit sandbox requests through Adobe support. See [Partner Adobe Commerce on Cloud infrastructure sandbox requests](https://experienceleague.adobe.com/en/docs/support-resources/adobe-support-tools-guide/adobe-commerce-support/partner-magento-commerce-cloud-sandbox-requests).

- **Commerce services**—Use sandbox API keys with the [Commerce Services Connector](/help/landing/saas.md) to test services integrations before connecting a production instance.
