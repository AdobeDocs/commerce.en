# Connect Adobe Commerce to AEM Assets for asset management

AEM Assets can be connected to Adobe Commerce through different integration paths, depending on the Commerce product.

For Adobe Commerce on cloud infrastructure, use the AEM Assets Integration for Commerce. For Adobe Commerce as a Cloud Service and Adobe Commerce Optimizer, use Product Visuals powered by AEM Assets.

>[!NOTE]
>
>This guide covers the AEM Assets integration paths for Adobe Commerce on cloud infrastructure, Adobe Commerce as a Cloud Service, and Adobe Commerce Optimizer. Follow the path that matches your product and deployment.

## Where to start

1. Review the [AEM Assets Integration for Commerce](/help/aem-assets-integration/overview.md) documentation for prerequisites and setup.


1. To enable asset management with AEM Assets, follow the [Next steps](/help/aem-assets-integration/overview.md#next-steps) instructions for your deployment type in the _[AEM Assets Integration for Commerce Guide](/help/aem-assets-integration/overview.md)_.
