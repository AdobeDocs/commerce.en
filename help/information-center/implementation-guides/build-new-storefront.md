# Build a new storefront

Adobe Commerce storefronts are built on Edge Delivery Services, combined with Commerce drop-in components and content blocks. Starting from the Adobe Commerce boilerplate gives you a working storefront that you can customize and connect to your own Adobe Commerce or [!DNL Adobe Commerce Optimizer] instance.

>[!NOTE]
>
>This guide applies to Adobe Commerce (on Cloud or on premises), Adobe Commerce as a Cloud Service, Adobe Commerce Optimizer connected to Adobe Commerce, and stand-alone Adobe Commerce Optimizer with an existing or third-party backend. See [Architecture options at a glance](../architecture-options/overview.md#architecture-options-at-a-glance) to confirm which option applies to your project.

## Where to start

1. Review the [Adobe Commerce Storefront overview](https://experienceleague.adobe.com/developer/commerce/storefront/) to understand the architecture and available drop-in components.
2. Follow the [storefront developer guide](https://experienceleague.adobe.com/developer/commerce/storefront/get-started/) to scope, set up, and launch a project.
3. Connect the storefront to your backend using the [Commerce Services Connector](/help/landing/saas.md) if you're using [!DNL Catalog Service], [!DNL Live Search], or [!DNL Product Recommendations], or the [[!DNL Adobe Commerce Optimizer Connector]](/help/aco-connector/overview.md) if you're using Adobe Commerce Optimizer.
