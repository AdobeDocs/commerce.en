# Integrate with Adobe Experience Platform

[!DNL Data Connection] sends behavioral, transactional, and profile data from Adobe Commerce to Adobe Experience Platform, so you can build customer segments and power personalized experiences with Real-Time CDP and Journey Optimizer.

>[!NOTE]
>
>This guide applies to Adobe Commerce on Cloud or on premises.

## Where to start

1. Review the [[!DNL Data Connection] introduction](/help/data-connection/overview.md) for prerequisites and setup.
2. Configure event data collection to enable behavioral data sharing, as described in [Configure Commerce Services](/help/landing/saas.md#saasenv).
