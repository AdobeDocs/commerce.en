# Configure payments

[!DNL Payment Services] gives shoppers multiple payment methods, including interest-free installments, and gives merchants a unified dashboard for managing payments, orders, and invoices.

>[!NOTE]
>
>This guide applies to Adobe Commerce (on Cloud or on premises), Adobe Commerce as a Cloud Service, and Adobe Commerce Optimizer projects.

## Where to start

1. Review the [[!DNL Payment Services] guide](/help/payment-services/guide-overview.md) for supported payment methods and prerequisites.
2. If you haven't connected Adobe Commerce to Commerce services yet, see [Set up Commerce services](set-up-commerce-services.md) first.
