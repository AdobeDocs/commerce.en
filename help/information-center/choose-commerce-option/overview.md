# Choose a Commerce option

Use the following questions to orient your decision:

1. **Do you need Commerce Foundation as the transactional commerce platform?**
   - Yes: Evaluate [!DNL Adobe Commerce] on Cloud or on premises, or [!DNL Adobe Commerce as a Cloud Service].
   - No: Evaluate stand-alone [!DNL Adobe Commerce Optimizer] with your existing or third-party commerce backend.
1. **Do you already operate [!DNL Adobe Commerce] on Cloud or on premises and want stronger discovery and merchandising?**
   - Yes: Evaluate the [!DNL Adobe Commerce Optimizer Connector].
1. **Do you want Adobe to manage the Commerce platform as SaaS?**
   - Yes: Evaluate [!DNL Adobe Commerce as a Cloud Service].

See [Architecture options](../architecture-options/overview.md) for the detailed system diagrams behind each option below.

## Adobe Commerce on Cloud

Best fit for customers that need the full [!DNL Adobe Commerce] platform with deployment control over cloud infrastructure. Commerce Foundation is the commerce and transaction system. See the [Adobe Commerce getting started guide](https://experienceleague.adobe.com/en/docs/commerce-admin/start/guide-overview).

## Adobe Commerce on premises

Best fit for customers that need the full [!DNL Adobe Commerce] platform with deployment control over on-premises infrastructure. Commerce Foundation is the commerce and transaction system. See the [Adobe Commerce getting started guide](https://experienceleague.adobe.com/en/docs/commerce-admin/start/guide-overview).

## Adobe Commerce as a Cloud Service

Best fit for customers that want Adobe-managed SaaS Commerce with reduced infrastructure ownership. Adobe-managed Commerce Foundation is the commerce and transaction system, and Commerce services are installed and configured automatically. See the [[!DNL Adobe Commerce as a Cloud Service] overview](/help/cloud-service/overview.md).

## Adobe Commerce Optimizer

Best fit for two situations:

- Customers with an existing [!DNL Adobe Commerce] deployment that want to add Optimizer discovery and merchandising capabilities through the [!DNL Adobe Commerce Optimizer Connector], while Commerce Foundation remains the system of record for transactions.
- Customers with an existing third-party transactional platform that want Adobe merchandising and discovery through a stand-alone [!DNL Adobe Commerce Optimizer] implementation.

See [What is Adobe Commerce Optimizer?](/help/optimizer/overview.md).

## Decision summary

| Customer situation | Starting point |
| --- | --- |
| New or existing implementation requiring a full [!DNL Adobe Commerce] platform with infrastructure control | [!DNL Adobe Commerce] on Cloud or on premises with Commerce Foundation |
| New implementation seeking a managed SaaS Commerce platform | [!DNL Adobe Commerce as a Cloud Service] with Commerce Foundation |
| Existing [!DNL Adobe Commerce] deployment needing advanced catalog discovery and merchandising | [!DNL Adobe Commerce Optimizer Connector] |
| Existing third-party transactional platform needing Adobe merchandising and discovery | Stand-alone [!DNL Adobe Commerce Optimizer] |
