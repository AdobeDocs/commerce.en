# Adobe Commerce product portfolio

Adobe Commerce spans several products and services. Use this page to understand how they fit together and find the right starting point for each.

## Core commerce

| Product | Description |
| --------- | --------------- |
| [Adobe Commerce](https://experienceleague.adobe.com/en/docs/commerce-admin/start/guide-overview) | The core commerce platform for building and running online stores, available on Adobe-managed cloud infrastructure (Adobe Commerce on Cloud) or on-premises. |
| [[!DNL Adobe Commerce as a Cloud Service] (ACCS)](/help/cloud-service/overview.md) | A cloud-native, fully managed SaaS version of Adobe Commerce, where Adobe handles infrastructure, updates, and scaling. |
| [[!DNL Adobe Commerce Optimizer] (ACO)](/help/optimizer/overview.md) | A composable merchandising and product discovery layer that connects to Adobe Commerce on Cloud or on premises through the [!DNL Adobe Commerce Optimizer Connector]. |

## Commerce services

[!DNL Catalog Service], [!DNL Live Search], and [!DNL Product Recommendations] extend Adobe Commerce and Adobe Commerce as a Cloud Service with AI-powered product discovery and recommendations. Adobe Commerce Optimizer customers get equivalent capabilities natively, under the name Product Discovery, instead of using these extensions.

| Service | Description | Availability |
| --------- | --------------- | --------------- |
| [[!DNL Catalog Service]](/help/catalog-service/overview.md) | Delivers an optimized, high-performance product catalog experience. | Adobe Commerce on Cloud and on premises, Adobe Commerce as a Cloud Service |
| [[!DNL Live Search]](/help/live-search/overview.md) | AI-powered search with typo tolerance and personalized, real-time results. | Adobe Commerce on Cloud and on premises, Adobe Commerce as a Cloud Service |
| [[!DNL Product Recommendations]](/help/product-recommendations/overview.md) | AI-fueled recommendations based on shopper behavior, popular trends, and product similarity. | Adobe Commerce on Cloud and on premises, Adobe Commerce as a Cloud Service |
| Product Discovery | Native facets, merchandising rules, and AI-driven ranking, provided directly by Adobe Commerce Optimizer in place of the Catalog Service, Live Search, and Product Recommendations extensions. See [Merchandising overview](/help/optimizer/merchandising/overview.md). | Adobe Commerce Optimizer, connected to Adobe Commerce on Cloud and on-premises with the Adobe Commerce Optimizer Connector |
| [[!DNL Payment Services]](/help/payment-services/guide-overview.md) | Multiple payment methods and a unified dashboard for payments, orders, and invoices. | All platforms |
| [Adobe I/O Events for Adobe Commerce](https://experienceleague.adobe.com/en/docs/commerce-learn/tutorials/extensibility/adobe-developer-app-builder/io-events/getting-started-io-events) | Event-driven integration between Commerce and Adobe App Builder applications. | All platforms |
| [AEM Assets Integration](/help/aem-assets-integration/overview.md) | Centralized digital asset management through Adobe Experience Manager Assets. | All platforms |

>[!NOTE]
>
>On Adobe Commerce as a Cloud Service, the Catalog Service, Live Search, and Product Recommendations extensions are installed and configured automatically. On Adobe Commerce on Cloud or on-premises projects, install each extension before you configure it. Adobe Commerce Optimizer is not currently available with Adobe Commerce as a Cloud Service. See [Get started](../get-started/overview.md) for role- and platform-specific setup paths.
